# 测试原始证据

在本目录按日期或计划日存放视频、串口日志、截图和波形，例如 `day01/BOOT-001-startup.mp4`、`day01/COM-002-uart.log`。

原始文件默认被 Git 忽略。测试结论写入 `../test_matrix.md` 和 `../reference_behavior.md`，同时记录证据文件名、采集日期、固件身份以及关键时间点。重要原始证据另存可靠位置，在记录中写明位置；需要长期审查的精简文本证据可以放在 `Docs/` 下并单独提交。

硬件已到位，Day 5 原始日志与波形保存在 `day05/`，精简结论和 SHA-256 登记在 `../daily/2026-09-14-day05.md` 与 `../day05_evidence_manifest.md`。每次采集记录固件提交、Debug/Release、ELF/BIN SHA-256、供电、连接、复位方式和采集时间。没有串口输出时记载“未观察到输出”及连接条件，不能据此编造日志或断言功能失败。
